# Learn SEO control

Source: `learn/manifest.json`. These values are written to the existing Yoast fields (`_yoast_wpseo_title`, `_yoast_wpseo_metadesc`, `_yoast_wpseo_opengraph-title`, `_yoast_wpseo_opengraph-description`) when that field is empty or still the value this seed last wrote.

A different non-empty Yoast value is left in place and reported as `seo-conflict`. Canonical URLs are not stored. On staging, the trial plugin points the canonical and Open Graph URL of a Learn page at `https://fides.community` plus the page path, and sets `noindex, nofollow`. On production, indexing and the canonical follow the existing site settings and the page permalink. The Open Graph image stays empty so Yoast uses the page image or the site default, which on production is `https://fides.community/app/uploads/2025/03/FIDES_LOGO_BLUE_03.png`.

The stored Training & workshops excerpt still begins “Join an open training in Utrecht” so the design shell keeps that intro. The meta description below does not use that sentence. Theme chrome already replaces the visible intro.
