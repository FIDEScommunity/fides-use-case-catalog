How can public organisations work with wallets?

Public organisations meet wallets from two sides. Many hold information that people need to prove, and many run services that need to receive it. The questions are similar in different countries. The answers depend on national law, existing registers and the wallets that are available.

A Dutch example, still in development

The articles use one Dutch programme as an example. Gemeenschappelijke Bronontsluiting (GBO), run by ICTU, is developing a standardised way for public bodies that hold authoritative data to make it available to the EUDI Wallet, to the European Once-Only Technical System (OOTS) and to private service providers that receive data with a citizen’s consent. The global design is described as a draft that is still in development. The version consulted is version 0.9.5 (September 2026), a draft design submitted for adoption. Other countries organise this differently, so read it as one example and not as a European model.
