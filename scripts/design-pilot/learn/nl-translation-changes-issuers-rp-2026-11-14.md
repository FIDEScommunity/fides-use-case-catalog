## Left English on purpose

- Catalog content: names, descriptions, accepted credentials, features, wallet and credential names, URLs.
- The generated result-row line (provider, country, "N credential configurations", "Accepts N credentials", "Updated <date>") and the counts. It is one string per record that mixes catalog content with interface text, so it has no reusable row.
- Query-specific texts ("No issuers match “…”"), page counters ("Page 1 of 3") and counts ("102 relying parties").
- Technical mode and format names: Proximity, Remote, SD-JWT VC, ISO mDoc and similar (decision of 14 November 2026).
