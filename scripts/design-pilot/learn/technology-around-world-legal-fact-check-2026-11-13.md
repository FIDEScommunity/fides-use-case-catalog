## Not verified or not possible

- **mdoc on the OpenID side**: no separate mdoc specification page of the OpenID Foundation exists; the OpenID4VCI/VP texts only reference ISO/IEC 18013-5. So the ISO page is the only added source.
- **ISO page by script**: blocked for curl (403, bot protection); content read through the web fetch tool, so the automated link test shows a warning, not a result.
- **EDI page by script**: needs a browser (JavaScript); not testable with curl. Content could only be read, not archived.
- **Dutch legislation** (the implementation act) and the **Dutch wallet**: no primary source on status or features was consulted; nothing is stated about them.
- **German news channels / social media**: only the programme's own website was consulted for a changed date.
- **The status of the ISO revision** ("expected ... within the coming months") is a plan of ISO and is not repeated beyond "due for revision".
- External links (OpenID, W3C, IETF, EC, ICTU, German programme, UNTP) answered 200 at the time of checking; the pilot test treats 403/429 as unverifiable.
